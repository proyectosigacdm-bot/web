# SIGA - Sistema Integrado de Gestión Académica

## 📋 Descripción

**SIGA** es una plataforma integral de gestión académica diseñada para instituciones educativas que buscan modernizar la administración de estudiantes, docentes, calificaciones y recursos académicos. Proporciona una solución centralizada, segura y escalable para optimizar los procesos educativos.

## ✨ Características Principales

- 👨‍🎓 **Gestión de Estudiantes**: Registro, perfiles, historial académico
- 👨‍🏫 **Administración de Docentes**: Asignación de cursos, horarios, evaluaciones
- 📊 **Sistema de Calificaciones**: Registro y seguimiento de notas en tiempo real
- 📅 **Gestión Académica**: Calendario, horarios, períodos lectivos
- 📚 **Recursos y Contenidos**: Materiales de estudio
- 📈 **Reportes y Análisis**: Dashboard con métricas de desempeño
- 🔐 **Seguridad**: Autenticación multi-nivel y control de acceso
- 📱 **Interfaz Responsiva**: Acceso desde cualquier dispositivo

## 🚀 Inicio Rápido

### Requisitos Previos

- Node.js v16 o superior
- Base de datos 
- npm o yarn


## 🛠️ Tecnologías Utilizadas

### Backend
- Mock DB en memoria (sin persistencia real)
- LocalStorage para sesión

### Frontend
- HTML5
- Tailwind CSS
- JavaScript Vanilla (ES6+)
- SheetJS (XLSX) para exportación a Excel
- FileReader API para carga de archivos

### DevOps
- SPA sin framework (Single Page Application vanilla)
- Capa de servicios simulada (api.js)
- Autenticación por token mock
